# Jyoti Thakur — GitHub Pages Portfolio

A recruiter-first portfolio focused on Product, Growth, GTM, UX and AI.

## Deploy
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
4. Replace `ADD-YOUR-EMAIL@example.com` in `index.html`.
5. Replace case-study placeholder text with verified project evidence, screenshots and links.

## Important
The portfolio deliberately avoids invented business metrics. Add only metrics and claims you can substantiate.
